# 项目定位

`readme-showcase` 是从仓库证据出发重新设计 GitHub 仓库主页的 Codex Skill，
不会虚构产品事实。

## 问题

仓库主页会漂移。README 声明了代码已经不再做的事情，或者重复任何项目都能
发布的通用营销语言。手工重写会重复同样的猜测。

## 这个项目做什么

单一 README Agent 扫描目标仓库、检索有许可证的编辑模式、编写项目原生文案与
视觉、检查每一个公开字节，最后停在带指纹的本地预览。

- 目标仓库公开声明只能来自仓库证据。
- 编辑模式塑造结构；目标证据仍是唯一事实来源。
- 候选资产绑定证据、语言、精确字节与有效替代文本。
- 门禁失败不能静默变成可发布结果。

## 边界

- 评估通过只授权本地审查。
- 提交、推送、发布与创建 Pull Request 始终需要另行明确批准。
- 默认运行不增加第三方 Python 运行时依赖。
- 运行状态保存在目标仓库外部的
  `${CODEX_HOME:-$HOME/.codex}/state/readme-showcase/`；不会创建每次 run
  专属的虚拟环境。

## 适合谁

适合希望 README 反映仓库真实行为、并且任何内容进入远端之前都能先审查本地
预览的维护者。
