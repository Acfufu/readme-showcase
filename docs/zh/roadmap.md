# 路线图

本页记录 `readme-showcase` 的现状与正在考虑的方向。列为计划的事项只是意图，
不是已完成的工作；这里的任何声明都不超出仓库当前展示的内容。

## 当前状态

- 八阶段交付：
  `扫描 → 检索 → 导入计划 → 生成请求 → 候选 → 组装 bundle → 校验 → 评估 →
  本地预览`。
- 五条命令——`shape`、`audit`、`redesign`、`polish` 与 `visualize`——路由到
  现有 `README`、`asset-only` 与 `audit-only` 模式。
- 英文 / 简体中文双语 README 与资产配对，由单一 README Agent 评估已验证的
  本地 bundle。
- 每条公开声明都绑定仓库证据；候选资产绑定证据、语言、精确字节与有效替代
  文本。
- 评估通过只授权本地审查。提交、推送、发布与创建 Pull Request 都分别需要
  另行明确批准。
- 运行状态保存在目标仓库外部的
  `${CODEX_HOME:-$HOME/.codex}/state/readme-showcase/`；不会创建每次 run
  专属的虚拟环境，也不会把状态目录放在目标旁边。
- 安装器是原子的：校验、锁、暂存、哈希、备份、替换与回滚，并做精确字节
  验证。

## 正在考虑

以下是候选方向。没有任何一项已承诺，也不改变批准门禁：

- 在 `docs/` 下提供用户文档，与 README 相同的 en / zh-Hans 配对（即本目录）。
- 更深入地覆盖动效与编译视觉路线，每条路线都保留其可编辑、受证据约束的
  源文件。
- 在检索数据集中增加更多编辑模式，始终通过许可证筛查并绑定来源。
- 更严格的内容断言，让文档与 README 声明在仓库变化时仍可验证。

## 我们不做的声明

- 不做自动远端发布；发布始终停留在明确批准之后。
- 不声称浏览器、线上或生产环境验证——只断言本仓库的 audit-only 运行时验收
  与本地硬门禁。
- 不改变八阶段管线；2 条隔离 `test` 模式永不进入生产检索。
